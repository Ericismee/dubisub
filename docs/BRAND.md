# DubiSub visual direction

Reference: https://elglabs.org/en/ . Public HTML/CSS inspected on 2026-10-17. Borrowed principles: white space, restrained typography, black/white hierarchy and a single violet accent. No ELG Labs logo, code or brand artwork copied.

Original mark: two offset open ribbons suggesting an S, subtitle lines and translation between tracks. Primary assets: assets/logo.svg, assets/logo-mono.svg, assets/wordmark.svg and assets/banner.svg. All use flat fills/strokes, no gradients.

Palette: white #FFFFFF, ink #15151A, violet #6A4DFF, muted #60626F, surface #F6F6F9, border #E9E9F0. Use one primary violet action and generous white space on a future landing page. Keep the logo clear at small sizes; use monochrome where needed. Avoid decorative chat icons, heavy shadows and multicolor gradients.

Typography direction: Lexend display, clean sans-serif body; SVGs reference Lexend with Segoe UI/Arial fallbacks. Font files are not embedded, so rendering depends on installed fonts. Bundle a properly licensed font or outline the final wordmark before enforcing identical rendering across platforms.

Future landing page: quiet navigation, concise headline, real product demo, workflow, capabilities, privacy/provider explanation, GitHub CTA and MIT footer. This document establishes direction; no landing page is implemented by this asset update.
